# Labs

Jupyter notebooks for the journeys in [instaclustr/labs](https://github.com/instaclustr/labs).

Each journey in `instaclustr/labs` is a full, hands-on build: you set up the infrastructure, load the data and work through the tasks. The notebooks here are the quick way in. You run the key steps and see the results, with the explanation next to the code you run. There is one folder per journey, with the same name as the journey.

> This code is a sample. It is not supported, so make sure you read and understand it before you run it in your own environment.

## Getting started

Each folder has its own README with the setup steps, prerequisites and what each notebook covers. Open the folder for the journey you want and follow its README.
