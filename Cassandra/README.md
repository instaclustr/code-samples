# Apache Cassandra Code Samples

## Description

The following folders contain code samples related to [Apache Cassandra](https://cassandra.apache.org/) on NetApp Instaclustr. These samples cover a range of Cassandra use cases including client connectivity, data modeling, and application patterns.

## Getting Started

Each sample has its own README that describes the sample, any prerequisites, examples, and anything else relevant to the code.

### Prerequisites

- Apache Cassandra cluster (e.g., [Instaclustr managed Apache Cassandra](https://www.instaclustr.com/platform/managed-apache-cassandra/))
- Additional prerequisites vary per project — see individual READMEs
