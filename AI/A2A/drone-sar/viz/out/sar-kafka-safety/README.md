# Kafka safety demo — viz artifact bundle

Generated by `./a2a/scripts/run-phase2-kafka-safety-demo.sh` using mission `missions/test-mission-kafka-safety.json`.

**Regenerate:**

```bash
scenarios/drone-sar/a2a/scripts/run-phase2-kafka-safety-demo.sh
```

Use **mission client** (demo script) — not Phase 1 `MissionRunner --viz-out`, which omits the `copilot` block.

---

## Files

| File | Description |
|------|-------------|
| `replay.json` | Full tick-by-tick replay + mission summary + **`copilot`** bundle (Tier 2 safety assessments) |
| `replay.html` | Canvas player with **Events**, **Mission narrator**, and **Safety analyst** side panels |
| `snapshot.png` | End-of-mission map (900×900) — drone paths, searched cells, no-fly zones, target found |
| `snapshot.svg` | Vector version of the same end state |

## View replay

Serve **this directory** (not the repo root):

```bash
cd scenarios/drone-sar/viz/out/sar-kafka-safety
python3 -m http.server 8768
# http://localhost:8768/replay.html
```

The status bar shows `· copilot` when `replay.json` includes the copilot block. Scrub to ticks **1, 12, 15–17, 76** to see safety analyst cards appear in sync with map events.

**Note:** `snapshot.png` is map-only — narrator and safety text appear in `replay.html`, not the PNG.

## Sample run (2026-08-27, template mode)

Mission **`sar-kafka-safety-demo`**, 3 drones, `demoViolations: true`, reduced battery on **d-03** (45% — flies the right lane, then LOW_BATTERY + emergency land), two no-fly zones.

### Mission summary

```json
{
  "ticksRun": 76,
  "searchedCellCount": 80,
  "allTargetsFound": true,
  "allRtbLanded": false,
  "anyEmergencyLand": true,
  "anyGeofenceViolation": true,
  "fleetRtbTick": 70,
  "foundTargetIds": ["t1"],
  "successCriteriaMet": false
}
```

`successCriteriaMet=false` is **expected** for this demo — violations are injected on purpose. The mission client exits **0** when `demoViolations: true` is set in the mission JSON.
